# 🌾 AI-Powered Sustainable Crop Production & Agricultural Decision Support System

An AI/ML-powered interactive web application for analyzing agricultural crop production data and providing sustainable decision-support insights across Indian states, districts, crops, and seasons.

## 📌 Project Description

This project transforms raw agricultural data into actionable decision-support insights using Machine Learning. Built with Python and Streamlit, it provides interactive analytics, crop production predictions, and sustainable agricultural recommendations.

Developed for the **1M1B AI for Sustainability Virtual Internship** in collaboration with **IBM SkillsBuild & AICTE**.

## 📋 Problem Statement

Farmers and agricultural decision-makers often need to make crop-production decisions using historical agricultural data. Understanding production patterns, crop productivity, seasonal trends, and expected production can help support better and more sustainable agricultural planning.

This application demonstrates how AI/ML can convert agricultural data into useful decision-support insights aligned with the United Nations Sustainable Development Goals.

## 🤖 AI/ML Methodology

### Model: Random Forest Regressor

The application uses a **Random Forest Regressor** model to predict crop production.

**Input Features:**
- `Area` — Cultivated area in hectares (numeric)
- `Season` — Agricultural season: Kharif, Rabi, Summer, Total (label-encoded)
- `Crop` — Crop type: 19 different crops (label-encoded)

**Target Variable:**
- `Production` — Crop production value

**Process:**
1. Data is cleaned and missing values are handled
2. Categorical features (Season, Crop) are label-encoded
3. Data is split into training (80%) and testing (20%) sets
4. A Random Forest Regressor is trained on the training data
5. Model performance is evaluated on the test set using MAE, RMSE, and R² metrics

**Important:** This is **AI/ML-powered agricultural decision support**. The project does not use generative AI, IBM Granite, RAG, or AI agents. All predictions are generated by a supervised machine learning model trained on historical data.

## ⚖️ Responsible AI

- **Fairness:** The model may reflect biases present in historical data
- **Transparency:** Predictions use a Random Forest model with openly displayed metrics
- **Privacy:** No personal data is collected from users
- **Accuracy:** Predictions are estimates, not guaranteed outcomes
- **Human Oversight:** Final decisions should involve farmers, experts, and local conditions
- **Data Limitations:** The dataset lacks weather, soil, irrigation, fertilizer, and pest data

## 🌱 Expected Impact

- Help farmers identify historically productive crop–season combinations
- Support agricultural officers in data-driven resource allocation
- Promote responsible crop production planning based on evidence
- Raise awareness of data limitations and the need for holistic agricultural planning
- Demonstrate responsible AI principles in real-world applications

## ⚠️ Limitations

1. **Historical Data Only:** The model cannot predict unprecedented events
2. **Missing Variables:** No weather, soil, rainfall, irrigation, fertilizer, or pest data
3. **Aggregated Data:** State/District-level aggregates, not individual farm data
4. **Single Time Period:** Dataset covers 2024-25 data only
5. **Prediction Uncertainty:** All predictions carry inherent uncertainty
6. **No Causal Claims:** The model identifies correlations, not causal relationships
7. **Expert Validation Required:** All insights need validation by domain experts

## 🚀 How to Run

```bash

```

## 💻 Example Usage

1. **Open the application** — The dashboard loads with the Project Overview section
2. **Use sidebar filters** — Select a State (e.g., "Uttar Pradesh"), Season (e.g., "Kharif"), and Crop (e.g., "Rice")
3. **View Analytics** — Navigate to "📊 Agricultural Analytics" to see production charts
4. **Make a Prediction** — Navigate to "🤖 AI Prediction", enter area, select season and crop, click "Predict Production"
5. **View Performance** — Navigate to "📈 Model Performance" to see MAE, RMSE, R² metrics
6. **Get Insights** — Navigate to "🧠 AI Insights" for data-driven agricultural patterns
7. **Get Recommendations** — Navigate to "🌱 Sustainable Decision Support" for contextual suggestions
8. **Review Responsible AI** — Navigate to "⚖️ Responsible AI" to understand model limitations
9. **Download Data** — Navigate to "📥 Download Results" to download the filtered dataset
